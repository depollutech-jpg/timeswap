<product_requirements>
The project, TimeSwap, is a mobile app for a service and time exchange community, designed to operate without monetary transactions. It features gamification elements like XP and levels to encourage user engagement.

**Core Functional Requirements:**
- **User Management:** Secure user registration, login, and password reset via email.
- **Role-Based Access:** A two-tiered system for user and admin roles, with specific accounts (, ) designated as administrators.
- **Service Marketplace:** A main feed where users can post and browse service offers and requests. This feed supports intelligent sorting by recency and the user's geographical proximity. Users have the ability to delete their own posts.
- **Private Messaging:** A complete chat system allowing users to initiate conversations directly from a service details page. The flow is: Ad on Home Feed -> Detailed Ad Page -> Contact button -> Private Chat Room.
- **Admin Dashboard:** A secure, dedicated section for administrators to view application statistics (e.g., user activity, financial flows via charts) and perform management tasks. Access is provided through a dedicated, secured Admin tab in the main navigation.
- **Dynamic UI:** The application features a horizontally scrollable bottom navigation bar to accommodate future expansion and subtle animations (bounce, slide) on the home page to enhance user experience.
</product_requirements>
