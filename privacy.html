🔒 Politique de Confidentialité - TimeSwap

Dernière mise à jour : 6 décembre 2025

1. Introduction

Bienvenue sur TimeSwap. Nous respectons votre vie privée et nous nous engageons à protéger vos données personnelles. Cette politique de confidentialité vous informe sur la manière dont nous collectons, utilisons et protégeons vos informations lorsque vous utilisez notre application mobile TimeSwap.

Éditeur de l'application :
• Nom : TimeSwap
• Site web : https://timeswap.fr
• Email de contact : support@timeswap.fr

2. Données que nous collectons

2.1 Informations que vous nous fournissez

Lorsque vous créez un compte, nous collectons :

  • Nom et prénom : Pour vous identifier sur la plateforme
  • Adresse email : Pour la connexion et les communications importantes
  • Mot de passe : Chiffré pour sécuriser votre compte
  • Photo de profil (optionnel) : Pour personnaliser votre profil
  • Numéro de téléphone (optionnel) : Pour faciliter les échanges
  • Description personnelle : Pour présenter vos compétences

2.2 Informations collectées automatiquement

Lors de l'utilisation de l'application :

  • Données de localisation : Pour vous proposer des services à proximité (avec votre consentement)
  • Photos : Si vous choisissez d'ajouter des photos à vos annonces
  • Messages de chat : Stockés de manière sécurisée pour faciliter la communication
  • Historique des services : Pour afficher vos échanges passés
  • Données d'utilisation : Pages visitées, fonctionnalités utilisées (via Google Analytics)

2.3 Informations sur les appareils

  • Type d'appareil (Android/iOS)
  • Système d'exploitation
  • Identifiant unique de l'appareil
  • Adresse IP
  • Informations de connexion

3. Comment nous utilisons vos données

3.1 Fournir nos services

  • Créer et gérer votre compte utilisateur
  • Permettre la publication et la recherche de services
  • Faciliter la communication entre membres (chat)
  • Organiser des rendez-vous entre utilisateurs
  • Gérer votre solde d'heures TimeSwap

3.2 Améliorer nos services

  • Analyser l'utilisation de l'application (via Google Analytics)
  • Comprendre les préférences des utilisateurs
  • Développer de nouvelles fonctionnalités
  • Corriger les bugs et problèmes techniques

3.3 Communications

  • Envoyer des notifications sur les nouveaux messages
  • Vous informer des rendez-vous à venir
  • Envoyer des emails de réinitialisation de mot de passe (via Resend)
  • Communiquer des mises à jour importantes de l'application

3.4 Sécurité et conformité

  • Prévenir la fraude et les abus
  • Respecter nos obligations légales
  • Résoudre les litiges entre utilisateurs

4. Base légale du traitement (RGPD)

Nous traitons vos données personnelles sur les bases légales suivantes :

  • Exécution d'un contrat : Pour fournir les services TimeSwap
  • Consentement : Pour la localisation, les notifications push, l'analyse
  • Intérêt légitime : Pour améliorer nos services et prévenir la fraude
  • Obligation légale : Pour respecter les lois applicables

5. Partage de vos données

5.1 Avec d'autres utilisateurs

Les informations suivantes sont visibles par les autres membres :

  • Nom et prénom
  • Photo de profil
  • Description personnelle
  • Services proposés
  • Avis et évaluations reçus
  • Localisation approximative (ville/quartier)
Nous ne partageons jamais :
• Votre adresse email complète
• Votre mot de passe
• Votre localisation précise sans votre consentement
• Vos messages privés avec d'autres utilisateurs

5.2 Avec des prestataires de services tiers

Nous utilisons des services tiers de confiance :

Service Utilisation Données partagées Pays
Google Firebase Analytics, authentification Données d'utilisation, ID appareil États-Unis
Stripe Paiements (achats d'heures) Informations de paiement États-Unis
Resend Envoi d'emails Adresse email États-Unis
MongoDB Atlas Stockage de données Toutes les données de profil États-Unis/Europe

Ces prestataires sont conformes au RGPD et protègent vos données.

5.3 Autorités légales

Nous pouvons divulguer vos informations si requis par la loi ou pour :

  • Répondre à une assignation ou ordonnance judiciaire
  • Protéger nos droits, votre sécurité ou celle d'autrui
  • Prévenir la fraude ou enquêter sur une activité illégale

6. Sécurité de vos données

Nous mettons en œuvre des mesures de sécurité pour protéger vos données :

  • Chiffrement : Toutes les communications sont chiffrées (HTTPS/TLS)
  • Mots de passe : Hachés avec des algorithmes sécurisés
  • Accès restreint : Seuls les administrateurs autorisés ont accès aux données
  • Sauvegardes : Effectuées régulièrement pour éviter la perte de données
  • Surveillance : Détection des activités suspectes

Cependant, aucune méthode de transmission sur Internet n'est 100% sécurisée.

7. Conservation des données

Nous conservons vos données personnelles :

Type de données Durée de conservation
Compte actif Tant que le compte est actif
Après suppression de compte 30 jours (puis suppression définitive)
Messages de chat 1 an après le dernier message
Historique des services 3 ans (pour statistiques)
Données de facturation 10 ans (obligation légale)

8. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

8.1 Droit d'accès

Vous pouvez demander une copie de toutes les données personnelles que nous détenons sur vous.

8.2 Droit de rectification

Vous pouvez corriger vos informations directement dans l'application ou nous demander de le faire.

8.3 Droit à l'effacement ("droit à l'oubli")

Vous pouvez supprimer votre compte et toutes vos données associées :

  • Dans l'application : Profil → Paramètres → Supprimer mon compte
  • Ou par email : support@timeswap.fr

8.4 Droit à la portabilité

Vous pouvez demander vos données dans un format structuré et lisible.

8.5 Droit d'opposition

Vous pouvez vous opposer au traitement de vos données à des fins de marketing ou d'analyse.

8.6 Droit de limitation

Vous pouvez demander la limitation du traitement dans certaines conditions.

8.7 Exercer vos droits

Pour exercer vos droits, contactez-nous :
• Email : support@timeswap.fr
• Objet : "Demande RGPD - [Votre demande]"
• Délai de réponse : 30 jours maximum

9. Données de localisation

9.1 Comment nous utilisons votre localisation

Nous utilisons votre localisation pour :

  • Afficher les services disponibles près de chez vous
  • Proposer des recommandations personnalisées
  • Améliorer la pertinence des résultats de recherche

9.2 Contrôle de la localisation

Vous pouvez à tout moment :

  • Activer/Désactiver : Paramètres appareil → TimeSwap → Localisation
  • Choisir la précision : Précise ou approximative
  • Révoquer le consentement : Aucune donnée de localisation ne sera plus collectée

10. Transferts internationaux de données

Vos données peuvent être transférées et stockées :

  • États-Unis : Firebase, Stripe, Resend
  • Europe : MongoDB Atlas (serveurs européens disponibles)

Ces transferts sont protégés par :

  • Clauses contractuelles types (CCT) approuvées par l'UE
  • Garanties appropriées conformes au RGPD
  • Privacy Shield (pour les entreprises certifiées)

11. Protection des mineurs

TimeSwap est destiné aux personnes âgées de 18 ans et plus.

Nous ne collectons pas sciemment de données personnelles d'enfants de moins de 18 ans. Si vous pensez qu'un mineur a créé un compte, contactez-nous immédiatement à support@timeswap.fr pour que nous puissions supprimer le compte.

12. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité occasionnellement. En cas de changement important, nous vous informerons :

  • Par notification dans l'application
  • Par email à votre adresse enregistrée
